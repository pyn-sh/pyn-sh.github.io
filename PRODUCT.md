# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack
Astro, Tailwind CSS v4, Manrope, Lucide icons (chosen by the project owner). Static build deployed to GitHub Pages at https://pyn-sh.github.io/.

## Users
Python developers who want to understand what Pyn plans to be, and people reading its planning documents.

## Product Purpose
Present the Pyn project: a planned Rust toolchain for Python with its own engine for packages, environments, tasks, testing, formatting, linting and, last, type checking, on standard CPython.

## Positioning
One independent tool with its own logic; it does not call other developer tools. A check that did not run is never reported as passed.

## Capabilities and Constraints
- Planning only: no code, no release, nothing to install, no benchmarks.
- The website renders every document from the `pyn-sh/pyn` repository, which stays the single source of truth.
- Name is a working name and no license has been chosen.

## Brand Commitments
Name "Pyn", tagline "The fast, all-in-one Python toolkit." (speed is a goal, not a measured result), and the supplied logo (`src/assets/pyn-logo-original.png`).

## Evidence on Hand
Planning documents, draft specifications and a logo. No users, testimonials, benchmarks or screenshots exist; none may be invented.

## Product Principles
1. State the status plainly.
2. Label planned behavior as planned.
3. Calm presentation; no hard sell.
